Recap · the setup

A synthetic world where we know the right answer

h = switch rate: a key’s value really changes. ε = typo rate: a copy shows value + 1.

An exact Bayes filter gives the ideal answer for every probe, so every model can be scored against it.

Models: 2-layer transformers, width 128, 4 heads, learnable ALiBi slopes; RoPE as a control.

The setup, in one picture. Training data are streams of key and value pairs: 16 keys, 64 values, 256 pairs per sequence, fresh random data every step so nothing is memorised. Each key has a hidden value. At every step it switches to a new random value with probability h, a real change. Each time it is shown, it can instead show a typo, the value plus one, with probability epsilon. Because we wrote the generator, an exact Bayes filter gives the best possible prediction. The measurement is the conflict probe at the bottom: n_c old copies of value c, then a gap of G pairs, then n_w recent copies of w = c plus 1, which looks exactly like a typo of c, then the query. We read off log p(c) over p(w) from the model and from Bayes. Positive means it trusts the old value, negative means the recent one. The models are small: 2 layers, width 128, 4 heads, about 150 thousand parameters, mostly attention-only, with a learnable ALiBi slope per head so we can read and edit how fast each head forgets.
