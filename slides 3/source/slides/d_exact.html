Three terms we had dropped; with them it is exact

1 · The next token can be a typo too (the biggest).
The model predicts the next copy, not the hidden value. If the value is c, the next copy shows w with chance ε, so c needs a head start to tie:
P(c)/P(w) = (1 − ε)/(1 − 2ε)
1.13 at ε = 0.1, 1.75 at ε = 0.3.
2 · A switch can land back on c.
Chance 1/V; the value is then still c, so story A gets s + (1 − s)/V.
time part: sV/(1 − s) → sV/(1 − s) + 1
Matters only when evidence is weak.
3 · The old copies could all be typos.
In story B the old value may have been c − 1, every old copy a typo.
R → R·(1 + ρnc), ρ = ε/(1 − ε)
1.11 for one old copy at ε = 0.1; ≈ 1 for two or more.
Before:  s/(1 − s) = R / V     →     Exact:  s/(1 − s) = [ R·(1 + ρnc)·(1 − ε)/(1 − 2ε) − 1 ] / V
R = ((1 − ε)/ε)nw, the evidence from the recent copies
Checked against an exact Bayes filter (tracks all 64 values step by step) on 920 cases: corrected switch gap off by 0.9% (median). The old formula: 47%, and 77% at ε ≥ 0.3.
Conclusions unchanged: old copies still don't matter, and each recent copy still moves the switch earlier by a fixed step. Only the numbers change, mostly at high ε.
When we re-derived the formula, the two-story logic held, but three terms had been dropped. The biggest: a language model predicts the next token, and the next token is itself a copy that can be a typo. If the hidden value is c, the next token shows w with chance epsilon. So c leaks some of its chance to w and needs a head start just to tie: the hidden odds must be (1 minus epsilon) over (1 minus 2 epsilon), 1.13 at epsilon 0.1 and 1.75 at 0.3. Second, a switch can land back on c, with chance 1 over V, which adds one to the time part; this matters only when the evidence is weak. Third, in story B the old copies could all have been typos of c minus 1, which multiplies the evidence by one plus rho to the n_c; that is 1.11 for one old copy and essentially one for more. With all three, the formula matches an exact Bayes filter to 0.9 percent in the median over 920 cases; the old one was off by 47 percent. The conclusions do not change.
