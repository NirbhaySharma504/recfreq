Background · the question

Old and frequent, or new and rare?

Harry Potter × 5, long ago
· · · gap of G steps · · ·
Harry Potyer × 1, just now
Harry ___ ?
If the world has typos (rate ε): "Potyer" is a slip. Trust the many old copies. Frequency wins.
If the world changes (switch rate h): the name really changed. Trust the recent copy. Recency wins.
Our setup: small transformers trained on key–value streams with both switches and typos. The data has an exact best answer (Bayes), so we can tell how each model decides, not just whether it is right.

Notation: h = switch rate · ε = typo rate · G = gap · nc = old copies · nw = recent copies · V = 64 possible values

The question came from Sir's Potter and Potyer example. When an induction head has seen a continuation often but long ago, and a conflicting one rarely but recently, which does it copy? Either answer can be right: if the world only has typos, frequency is right; if the world really changes, recency is right. So we built a task with both: each key's value is redrawn at rate h, and each copy is corrupted at rate epsilon. Because the data comes from known rules, there is an exact best answer, the Bayes predictor, and we can compare every trained model to it.
